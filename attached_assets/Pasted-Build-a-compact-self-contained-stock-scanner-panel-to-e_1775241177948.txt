Build a compact, self-contained stock scanner panel to embed in my existing site. 

STACK: HTML + CSS + JS (vanilla). Use the Finviz screener API proxy or Alpha Vantage free tier for data (add a placeholder for the API key).

DESIGN AESTHETIC:
- Dark terminal/trading desk theme — deep charcoal background (#0d0f14), neon green accents (#00ff88), monospaced font (JetBrains Mono or Fira Code from Google Fonts)
- Compact card layout — fits in a ~480px wide sidebar or widget container
- Subtle scanline or grid texture on background
- Color-coded price change cells: green for positive, red for negative, with glow pulse on update

FEATURES TO INCLUDE:
1. FILTER BAR (top row, collapsible):
   - Market cap: Micro / Small / Mid / Large
   - Sector dropdown
   - Price range slider ($1–$500)
   - Volume filter (>500K, >1M, >5M)
   - % Change filter (>2%, >5%, >10%)

2. SCANNER TABLE (main view):
   Columns: Ticker | Price | % Chg | Volume | Mkt Cap | RSI | Float | Rel Volume
   - Sortable columns (click header)
   - Max 20 rows visible, scrollable
   - Row click opens a mini detail panel (right side or modal): 52-week range, sector, short float, earnings date
   - Highlight rows where RSI < 30 (oversold) or RSI > 70 (overbought)

3. PRESET SCAN BUTTONS (below filter bar):
   - "Momentum" (>5% chg, vol >1M)
   - "Oversold Bounce" (RSI < 32, green today)
   - "High Volume Spike" (Rel Vol > 3x)
   - "Small Cap Runners" (float <10M, >4% chg)
   Each preset auto-populates filters and refreshes results.

4. AUTO-REFRESH TOGGLE:
   - 30s / 60s / Off selector in top-right corner
   - Live countdown ring/timer indicator
   - Flash animation on rows that changed since last refresh

5. EXPORT BUTTON:
   - "Export CSV" downloads current results

6. WATCHLIST STAR:
   - Star icon on each row saves ticker to localStorage watchlist
   - Watchlist tab shows saved tickers with current price

LAYOUT:
- Total widget width: 480px max, responsive down to 360px
- Scanner table height: 420px fixed with internal scroll
- Filter bar collapses to a single "Filters" toggle button on mobile

API NOTES:
- Add a config object at the top of the JS file with placeholder API keys
- Use mock/demo data by default so it renders without a key
- Comment clearly where to swap in live API calls (Finviz, Alpha Vantage, Polygon.io, or Yahoo Finance via RapidAPI)

Make the UI feel like a Bloomberg terminal widget — dense, data-rich, but clean. No rounded corners on the table. Sharp edges, tight padding (4px–8px rows), uppercase ticker labels.
